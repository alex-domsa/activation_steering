# activation_steering
Activation Steering and Analogous Sentence Pairs

BSc Computer Science & Software Engineering final-year project. It asks whether literal and metaphorical (analogical) language can be distinguished from the activations they cause inside a language model. The work builds on structure-mapping theory (Gentner & Markman) and Contrastive Activation Addition (Rimsky et al., 2024). It compares activations across layers for analogous and non-analogous sentence pairs, and, if a consistent direction emerges, tests it by steering the model.
